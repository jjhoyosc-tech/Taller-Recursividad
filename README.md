# Taller de Recursividad

**Estudiante:** Juan Jose Hoyos Calvache 

## Descripción

Repositorio correspondiente al taller de recursividad. Contiene la solución en Java de trece ejercicios que abarcan factorial, sumatorias, inversión de números, suma de dígitos, potencia, máximo común divisor, cociente y multiplicación por métodos sucesivos, suma de arreglos y matrices, serie de Fibonacci y función de Ackerman.

Todos los ejercicios están implementados mediante funciones recursivas y se ejecutan a través de un menú interactivo en consola.

## Requisitos

- Java 17 o superior.
- Visual Studio Code con la extensión Extension Pack for Java (o cualquier IDE compatible).

## Instrucciones de ejecución

1. Clonar el repositorio:
   git clone https://github.com/jjhoyosc-tech/Taller-Recursividad.git

2. Abrir la carpeta del proyecto en Visual Studio Code.

3. Ejecutar el archivo Main.java ubicado en src/Recursividad/.

4. Seleccionar en el menú la opción correspondiente al ejercicio que se desea probar e ingresar los datos solicitados.

## Ejercicios incluidos

1. Factorial de un número.
2. Sumatoria hasta un número n.
3. Sumatoria de la serie 1 + 1/2 + 1/3 + ... + 1/n.
4. Inversión de un número entero.
5. Suma de los dígitos de un número.
6. Potencia de una base elevada a un exponente.
7. Máximo común divisor mediante el algoritmo de Euclides.
8. Cociente de división entera por restas sucesivas.
9. Multiplicación por sumas sucesivas.
10. Suma de los elementos de un arreglo.
11. Suma de los elementos de una matriz.
12. Serie de Fibonacci hasta un límite dado.
13. Función de Ackerman para dos valores enteros.
